## About

This is a rebuild and update of a [Datawrapper visualisation](https://datawrapper.dwcdn.net/okoW0/2/) I originally created in 2024. I revisited the data while learning to use Tableau, using the opportunity to recreate the visualisation in a new tool.

The aim is to present publicly available data on GP patient registrations alongside information about the IT systems and suppliers used by GP practices.

## Data sources

The visualisation draws on publicly available data from NHS England:

- **Patients registered at a GP practice:** [NHS England – Patients Registered at a GP Practice](https://digital.nhs.uk/data-and-information/publications/statistical/patients-registered-at-a-gp-practice)
- **GP IT system suppliers:** [NHS England – MI Patient Online (POMI)](https://digital.nhs.uk/data-and-information/publications/statistical/mi-patient-online-pomi)

## Data limitations

The latest version of the GP IT supplier breakdown I have been able to locate is from **September 2024**. I have not been able to find a more recent breakdown of GP system suppliers, and a Freedom of Information (FOI) response confirmed that the information is not available.

As a result, the supplier data may not reflect the current distribution of GP IT systems. This limitation should be considered when interpreting the visualisation.
